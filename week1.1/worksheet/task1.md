# Terminal Commands

You have been introduced to a variety of terminal commands this week – fill out the table with an explanation for each command which says what it is used for.

You may find it useful to run these commands in the terminal of Codespace to remind yourself.

You should put your explanations between the \| \| characters.

You can complete this task on the worksheet pdf if you prefer.

|     Command                 |     Explanation    |
|-----------------------------|--------------------|
|     pwd                     | shows the current location of the terminal |
|     ls                      | shows all the files and directories in the current directory|
|     cd directory_name       | moves to the named directory |
|     cd ..                   | moves to the parent of the current directory |
|     cd -                    | goes to the previous directory|
|     mkdir directory_name    | makes a new directory with the entered name|
|     touch filename          | creates a file with the entered name |
|     git status              | shows the status of the git repository, e.g, whether git can be pushed or needs to be pulled |
|     git add -A              | stages the changes made onto git|
|     git commit -m ""        | commits the staged changes with message |
|     git push                | pushes the commited changes to git |
|     git pull                | pulls the current repository from git |
